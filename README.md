# Mobile Lock System 🔐

A simple Java-based Mobile Lock / PIN Control System with a modern web-style interface.  
This project allows users to:

- Set a PIN
- Unlock the mobile
- Change the PIN
- Lock the mobile again
- Validate PIN rules
- Display access messages

---

## 📌 Features

✅ Set a secure PIN  
✅ Unlock mobile using PIN  
✅ Change existing PIN  
✅ Lock mobile again  
✅ PIN validation (4–8 digits)  
✅ Access granted / denied messages  
✅ Simple and attractive UI  

---

## 🛠️ Technologies Used

- Java
- Java Swing / GUI
- VS Code
